# 結合・機能テスト仕様（IT）

対象システム: 簡易POSアプリ（Lv1＋Lv2）。基準資料は`07_要件定義書.md`・`設計仕様書.md`。

**前提**: 単体テスト（UT）で確認済みの計算ロジック・バリデーションの詳細（境界値の網羅等）は本レベルでは繰り返さない（`20260909_テスト.pdf` p.10の方針）。ITでは、フロントエンド（BFF：Next.js API Routes）⇔バックエンド（FastAPI）⇔DBの連携、認証・認可、エラー伝播、状態遷移を中心に検証する。実装が存在しないため、テスト対象は設計仕様書6章（API設計）・7.4節（認証・認可設計）に基づく。
